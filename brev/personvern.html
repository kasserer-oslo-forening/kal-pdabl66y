Personvernerklæring for Brev

Sist oppdatert 28. november 2026.

Brev er en e-postapp for iPhone. Appen kobler seg direkte fra telefonen til brukerens egne e-postservere (for Gmail: Googles IMAP- og SMTP-servere).

Hva appen bruker

Med brukerens samtykke får appen tilgang til Gmail-kontoen (omfanget https://mail.google.com/) for å vise, sortere, sende, arkivere og slette e-post, og til e-postadressen for å vite hvilken konto som er logget inn.

Hva som lagres

Innloggingsnøkler lagres kryptert i iPhonens nøkkelring. Innstillinger, regler og filtre lagres bare på telefonen. Ingen e-post eller andre data sendes til eller lagres på andre servere enn brukerens egne e-postservere, og ingenting deles med tredjeparter eller brukes til reklame eller analyse.

Bruk av Google-data

Brevs bruk av informasjon mottatt fra Google API-er følger Google API Services User Data Policy, inkludert kravene om begrenset bruk (Limited Use).

Slette data

Slett kontoen i appens innstillinger eller slett appen. Tilgangen kan også trekkes tilbake på myaccount.google.com/permissions.

English summary: Brev connects directly from the iPhone to the user's own mail servers. Google user data (Gmail access via https://mail.google.com/ and the account email) is used only to show, organize and send the user's own email, is stored only on the device (tokens in the iOS Keychain), and is never sent to other servers, shared with third parties, or used for advertising. Brev's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
